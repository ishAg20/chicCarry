# chicCarry

chicCarry is a full-featured eCommerce web platform designed for seamless online shopping experiences. It features user authentication, order management, product filtering, and responsive UI optimized for devices of all sizes.

## Demo

Visit the live site: [chicCarry](https://chiccarry.onrender.com/)

## Features

- User registration, login, and secure authentication  
- Product catalog with search and advanced filtering options  
- Intuitive product pages with images, descriptions, pricing, and reviews  
- Shopping cart with add/remove/update product functionality  
- Order management system for tracking order status and history  
- Responsive design ensuring smooth experience on mobile, tablet, and desktop  
- Admin dashboard for managing products, orders, and users  

## Technologies Used

- Frontend templating with EJS  
- Backend powered by Node.js and Express.js  
- Database integration with MongoDB  
- JavaScript for client-side interactivity  

## Installation

1. Clone the repository  
```
git clone https://github.com/ishAg20/chicCarry.git
```

2. Navigate to the project folder  
```
cd chicCarry
```

3. Install dependencies  
```
npm install
```

4. Set up your MongoDB connection string in `.env` file  

5. Start the server 
``` 
npm start
```

6. Open your browser at `http://localhost:3000`
